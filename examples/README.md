# Examples

Place driver usage examples and CubeIDE integration snippets in this directory.

Each example should include:

- Target STM32 board or MCU family
- Required CubeMX peripheral configuration
- Driver files used from `drivers/`
- `main.c` integration snippet
- Expected output or test result

## Available Examples

| Example | Driver |
| --- | --- |
| `uart_logger_usage.md` | `drivers/uart_logger` |
| `uart_logger_basic/` | `drivers/uart_logger` |
