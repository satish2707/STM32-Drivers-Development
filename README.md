# STM32 Drivers Development

Dedicated repository for STM32CubeIDE device driver development.

## Driver Modules

| Folder | Purpose |
| --- | --- |
| `STM32_CAN/` | STM32 CAN driver development and examples. |
| `STM32_ExFlash/` | STM32 external flash memory driver development. |
| `STM32_Logger/` | STM32 UART/debug logger driver development. |
| `STM32_Modbus/` | STM32 Modbus protocol driver development. |
| `STM32_RTC/` | STM32 RTC driver development. |

## Standard Driver Structure

Each driver folder can follow this layout:

```text
STM32_<DriverName>/
  Inc/
  Src/
  Examples/
  Docs/
  README.md
```
