# Projects

Use this directory for optional STM32CubeIDE demonstration projects.

Recommended approach:

1. Keep reusable driver code in `drivers/`.
2. Keep CubeIDE board-specific demo projects in `projects/`.
3. Commit `.ioc`, `.project`, `.cproject`, source files, and documentation when a full demo project is needed.
4. Do not commit generated build folders such as `Debug/` or `Release/`.
