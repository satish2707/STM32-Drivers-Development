# Device Driver Development

This folder is reserved for reusable STM32 device driver development.

## Purpose

- Store reusable STM32 HAL/LL driver libraries.
- Keep driver documentation, examples, and integration notes together.
- Use this workspace for STM32CubeIDE based driver development.

## Recommended Structure

```text
Device_Driver_Development/
  Drivers/
  Examples/
  Docs/
```
